## 发现与完成项

1. 高优先级：域名 endsWith 校验接受伪造后缀域名，爱奇艺路径还接受非 HTTP 协议。改为精确域名或点分隔子域名，并拒绝非 HTTP(S) 及携带凭据的 URL。
2. 高优先级：过滤无效 cid 导致后续 cid 前移、集数错位。保留位置并使用 0 占位，不向播放器传入无效 cid。自定义合集集数改为有效 items 长度，避免空集。
3. 中优先级：B站分享链接丢失 p 参数。保留分集参数；原 iframe 的 aid/cid/p 继续保留。
4. 中优先级：失效的历史选集或已移除合集未被校正。载入时重新限定集数、检查合集 ID；损坏的 Cookie 编码不再抛出解析异常。
5. 中优先级：合集请求失败静默显示备用内容。增加加载状态、备用提示及重试。
6. 使用体验：增加合集名称搜索与无结果提示；首尾集禁用越界按钮。
7. 无障碍：移除包裹多个按钮的伪按钮角色；补齐导航和输入框标签、当前路由状态、选集展开状态；弹层打开聚焦当前集，Esc 关闭恢复焦点。原先已有点击外部关闭，已合并维护，并非本轮首次新增。
8. 全屏：捕获异步拒绝，不支持或失败时回退剧场模式；剧场模式支持 Esc 退出并恢复页面滚动。

以上结论直接依据修改前后源码和回归检查，置信度高；不表示已完成所有第三方播放兼容性验证。
